Doclyst

Fill DOCX and PDF templates from a spreadsheet — one document per row.

Everything happens on this device. Your template, your spreadsheet and every value in it stay in this browser tab. Nothing is uploaded — this page is blocked from making network requests at all.

1 Template

A .docx with {{PLACEHOLDERS}} in the text, or a .pdf with form fields named after your columns.

2 Data

A .csv or .xlsx whose header row names the fields.

3 Options

Leave blank to number files by position. A filename is visible without opening the file, so naming documents after an identifier discloses it to anyone who can see the folder. Use {{FIELD}} and {{ROW}}.

4 Generate

“Save to folder” and “Save as ZIP” write each document to disk as it is made, so memory stays flat no matter how large the batch. Your browser asks where to save; this page can only write to the place you pick, and only for this visit.

Doclyst implements privacy and security controls that support responsible handling of personal data. It is not a compliance product and does not make any organisation PDPA-compliant.
