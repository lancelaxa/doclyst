Doclyst

One document per row, from a template and a spreadsheet.

Nothing leaves this device. Your files and every value in them stay in this tab — the page is blocked from making network requests at all.

1

Template

A .docx or .pdf with {{PLACEHOLDERS}} named after your columns.

To keep your letterhead exactly: write the placeholders in Word, save as PDF, and drop that here — Doclyst adds the fields for you.

This PDF still has {{PLACEHOLDERS}} in it. Each becomes a fillable field; the rest of the page is untouched.

2

Data

A .csv or .xlsx. The header row names the fields — a Full Name column fills {{FULL_NAME}}.

3

Options

Sensible defaults. Change only what you need.

Blank numbers them document-0001. Use {{FIELD}} or {{ROW}} to name from your data — but a filename is readable without opening the file, so avoid identifiers.

A PDF template gives an exact copy. PDF from a .docx re-typesets the text — wording exact, appearance approximate — and warns you if anything cannot be carried over.

4

Generate

One document per row. Open one before you send the batch.

“Save to folder” and “Save as ZIP” write each document straight to disk, so memory stays flat however large the batch. This page can write only where you choose, and only for this visit.

Doclyst implements privacy and security controls that support responsible handling of personal data. It is not a compliance product and does not make any organisation PDPA-compliant.
